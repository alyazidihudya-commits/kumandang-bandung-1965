# Kumandang Bandung 1965

Situs resmi komunitas dengan **Next.js 14 (App Router)**, TypeScript, dan Tailwind CSS.

## Struktur

- `app/` — halaman: beranda, tentang, struktur-organisasi, agenda, galeri, kontak
- `components/` — Navbar, Footer, Hero, Card
- `data/` — JSON pengurus, agenda, galeri
- `public/images/` — aset foto

Headline memakai **Space Grotesk** (`font-display`). Body memakai Inter. Basis warna gelap (`ink-*`) dengan aksen cyan.

## Menjalankan

Butuh Node.js 18+ dan npm.

```bash
npm install
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000).
